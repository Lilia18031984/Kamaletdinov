# 🎬 Movie Library

Приложение для хранения информации о фильмах с графическим интерфейсом на Tkinter.

## 👤 Автор
**Камалетдинов Роман** 
## 📋 Описание

Movie Library — это десктопное приложение, которое позволяет:
- Добавлять фильмы с указанием названия, жанра, года выпуска и рейтинга
- Просматривать все фильмы в виде таблицы
- Фильтровать фильмы по жанру и году выпуска
- Просматривать статистику (общее количество, средний рейтинг, лучший фильм)
- Сохранять данные между запусками программы

## 🚀 Установка и запуск

### Требования
- Python 3.6 или выше
- Tkinter (входит в стандартную библиотеку Python)
